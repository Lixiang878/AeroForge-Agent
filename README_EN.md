# AeroForge-Agent

An offline-first CFD workflow for vehicle wind-field studies. It parses requirements, generates or validates closed STL geometry (including traced DrivAerML vehicle meshes), prepares OpenFOAM dictionaries, runs `simpleFoam` or `pimpleFoam`, applies mesh/solver evidence gates, and produces reports from real OpenFOAM fields only. Named production vehicles require a licensed local mesh plus a provenance/license/SHA-256 manifest and never silently fall back to the simplified smoke-test car.

Run `pip install -e '.[dev]'`, then `python examples/demo_bmw_x3.py x3.stl x3.manifest.json` and `pytest -q`. Use `--vehicle-color "#1A80E6" --animation` for configurable body paint and an honestly labelled real-field animation: steady results default to massless tracer advection in frozen `U(x)` using actual `IntegrationTime`; the visualiser seeds a finite near-body YZ plane (15×11), uses fixed-length U-oriented arrows, and reserves colour for `|U|`. Figures use the perceptually ordered Viridis map (Cividis fallback), choose limits from the valid sampled speed range with small headroom, and switch to a physically labelled log10 scale only when the sampled speed range is wide. The generated HTML viewer adds a physical-speed colourbar, time slider, Play/Pause controls, preset cameras, mouse orbit and wheel zoom; the default 120-frame playback is 40 fps (about 3 s). `--animation-mode steady_orbit` is an explicit camera-orbit alternative. Neither is transient turbulence. Transient animation uses physical `pimpleFoam` time steps and refuses to relabel short or unknown runs as steady. For the public real-vehicle smoke path, use `python examples/run_drivaerml.py body.stl`; provenance and licensing are documented in [`docs/REAL_VEHICLE_MODEL.md`](docs/REAL_VEHICLE_MODEL.md), while brand-model acquisition boundaries are in [`docs/VEHICLE_ASSET_POLICY.md`](docs/VEHICLE_ASSET_POLICY.md). Without OpenFOAM the pipeline is an explicit dry-run; without residual, continuity, log-end, and fresh force-coefficient evidence, it is not reported as converged. See [`docs/AUDIT_2026-08-30.md`](docs/AUDIT_2026-08-30.md) for the latest review and known CFD limitations.
