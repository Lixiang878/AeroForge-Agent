# Ahmed body 基准验证档案

> 基准：Ahmed et al. (1984), SAE 840300，Re ≈ 2.78e6（U=40 m/s，L=1.044 m，空气）。
> 流程：参数化 STL → 从零生成 case → blockMesh + surfaceFeatureExtract +
> snappyHexMesh + checkMesh → simpleFoam（k-ω SST 稳态 RANS，壁面函数）→
> forceCoeffs（迎风面积归一，稳态尾段均值）。运行时：WSL / OpenFOAM v2412。

## 验证结果汇总

| # | 几何 | 斜角 | 网格设置 | 单元数 | 计算 Cd | 实验参考 | 偏差 |
|---|------|------|----------|--------|---------|----------|------|

## 已确认的系统性因素与修正记录

1. **尖角前缘**（#1 → #2）：平直前立面导致前缘大分离，Cd 达平板量级（~1.05）。
   加入实验几何的前鼻圆角（顶 R100 mm / 底 R50 mm）后 Cd 降至 0.58。
   结论：圆角是复现实验 Cd 的必要几何特征，已固化进生成器。
2. **网格分辨率与尾流**（#2 → #3）：表面加密 level 2→3 并加尾流加密盒，
   25° 工况 Cd 0.582→0.559，方向正确但幅度有限。
3. **区块阻塞比**（#4 → #5）：原域横截面对迎风面积阻塞比 ≈ 11%，超出
   汽车风洞 <5% 的工程惯例，会系统性抬高 Cd；已扩域至阻塞比 ≈ 4%。
4. **入口湍流**（#4 → #5）：I 由 1% 降至 0.5%、长度尺度 7%L 降至 3%L，
   贴近风洞低湍流条件，推迟人为分离；与扩域叠加后 20° 工况
   Cd 0.547 → 0.493，继续同向改善但未达容差。

## 如实声明的剩余偏差来源（未完全消除）

- **上游地面边界层**：移动地面自入口发展 ~3L 后厚度可达 ~45 mm，与
  50 mm 离地间隙同量级；实验风洞用边界层吸除规避，本流程未建模，
  会削弱车底流动、抬高压差阻力。
- **稳态 RANS + 壁面函数**：25° 处于分离双稳态过渡区，稳态假设本身
  高估分离（文献 RANS 散布 0.30–0.55+）；20° 附体角偏差更可能来自
  上述几何/边界层因素而非湍流模型。
- **简化几何**：无支腿、无后视镜等附件；无圆角离散化误差（8 段圆弧）。

## 结论与改进路线

当前流程在**趋势与量级上自洽**（尖角→圆角、网格加密、域扩大均使 Cd
单调趋向实验值），但绝对精度尚未达到 ±10% 判据。达到判据的路线（按
性价比排序）：
1. 消除上游地面边界层影响（抬高计算域入口处理 / 缩短上游长度并加
   速度型修正）；
2. 网格再加密一倍并降低 y+（低雷诺近壁处理替代壁面函数）；
3. 25° 工况改用瞬态求解（pimpleFoam）或尺度解析方法（DES/LES）。

本档案与 `workspace/*/results/verification_report.md` 一并构成可追溯的
验证记录；所有数值均为真实求解输出，无 dry-run 混入。
