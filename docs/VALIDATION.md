# Ahmed body 基准验证档案

> 基准：Ahmed et al. (1984), SAE 840300，Re ≈ 2.78e6（U=40 m/s，L=1.044 m，空气）。
> 流程：参数化 STL → 从零生成 case → blockMesh + surfaceFeatureExtract +
> snappyHexMesh + checkMesh → simpleFoam（k-ω SST 稳态 RANS，壁面函数）→
> forceCoeffs（迎风面积归一，稳态尾段均值）。运行时：WSL / OpenFOAM v2412。

## 已确认的系统性因素与修正记录

1. **尖角前缘**（#1 → #2）：平直前立面导致前缘大分离，Cd 达平板量级（~1.05）。
   加入实验几何的前鼻圆角（顶 R100 mm / 底 R50 mm）后 Cd 降至 0.58。
   结论：圆角是复现实验 Cd 的必要几何特征，已固化进生成器。
2. **网格分辨率与尾流**（#2 → #3）：表面加密 level 2→3 并加尾流加密盒，
   25° 工况 Cd 0.582→0.559，方向正确但幅度有限。
3. **区块阻塞比**（#4 → #5）：原域横截面对迎风面积阻塞比 ≈ 11%，超出
   汽车风洞 <5% 的工程惯例，会系统性抬高 Cd；已扩域至阻塞比 ≈ 4%。
4. **入口湍流**（#4 → #5 → #7）：I 1%→0.5%，随后改用远场粘度比
   nut/nu=5 定义 omega（外气动低湍流风洞惯例），Cd 0.547 → 0.493 → 0.487。
5. **上游地面滑移**（#5 → #6）：上游地面改 symmetryPlane（模拟风洞
   边界层吸除），仅体前 0.75L 起为移动地面；Cd 变化 <0.5%，非主导因素。
6. **wakeBox 语法根因**（#8）：#3–#7 的尾流加密盒采用内联 searchableBox
   写法，被 ESI 版 snappyHexMesh 静默忽略（日志 “entries were not used”），
   即此前各轮实际均无尾流加密；修正为 geometry 节定义 + refinementRegions
   按名引用后，#8 网格增至 115 万单元，Cd 仍≈ 0.49。

## 八轮实验的综合结论（v0.2.0 记录，已被 v0.3.0 修订）

设置级修正（几何圆角、阻塞比、入口湍流、地面处理、尾流加密）在 #1→#5
把 Cd 从 1.056 拉到 0.49 后全部进入平台期。v0.2.0 将平台期归因于
"模型形态（RANS+壁面函数）+无支腿简化几何"——**该归因已被 v0.3.0
复核推翻**，见下节。

## v0.3.0 根因修订与对照实验（#9–#12）

**力系数分解语义纠错**：`coefficient.dat` 的 `Cd(f)/Cd(r)` 列并非
摩擦/压差分解（实测各约为 Cd 之半）；真实分解在求解日志 forceCoeffs 块的
Pressure/Viscous 列。据此重审 #1–#8：**摩擦分量始终正常（0.018–0.019），
压差阻力 0.486 占 Cd 的 96%**——"壁面函数高估摩擦"假设不成立。

**对照实验链**（每轮只改一个变量）：
- #9 换 Spalding 连续律壁面函数：Cd 仅 -4.5% → 壁面函数类型非主因；
- #10 仅把 STL 圆角 8→24 段：Cd 仅 -1.2% → 几何离散单独无效
  （网格 6.5cm 仍解析不了曲率）；
- #11 前缘加密盒 level5（圆角弧 ~10 单元）+ 尾流盒生效：526 万单元，
  **Cd 0.491→0.449（-8.4%）**，其中压差 0.486→0.418（-14%）、
  摩擦 0.018→0.031（回归文献量级）→ **前缘分辨率是可操作的主改善项**；
- #12 低 Re 15 层大网格（902 万）：SIMPLE/SIMPLEC 均呈极限环震荡
  （层覆盖率 62% 的过渡区 + 极大长宽比），稳态求解器不收敛——
  工程结论：低 Re 积分到壁面需配合层覆盖率 100% 的更稳网格或瞬态求解。

**分区 Cp 证据**（`examples/surface_cp_zones.py`，#6 vs #11 收敛场对比）：

| 分区 | #6（v0.2.0）Cp / 贡献 | #11（v0.3.0）Cp / 贡献 | 文献量级（20°） |
|------|----------------------|------------------------|----------------|
| 前表面（0.073 m²） | +0.618 / +0.415 | +0.616 / +0.399 | 贡献 ≈ +0.27 |
| 斜面（0.087 m²） | −0.221 / +0.057 | −0.288 / +0.075 | 附体，贡献小 |
| 基座（0.083 m²） | −0.090 / +0.066 | −0.106 / +0.078 | Cp −0.2~−0.3 |
| 摩擦 Cd | 0.018 | 0.031 | 0.03–0.05 |

**剩余偏差定量分解**（Cd 0.449 − 0.197 ≈ 0.25）：
- 前缘加速区不完全：前表面贡献 +0.40 vs 文献 ≈+0.27 → **+0.13**；
- 基座吸力不足：Cp −0.11 vs 文献 −0.2~−0.3 → **+0.07**；
- 其余为斜面/顶底侧面压力分布细节差异。

## 剩余偏差来源（v0.3.0 修订）

- **前缘近壁分辨率**：#11 圆角弧上已达 ~10 单元，但圆角区边界层仍由
  2 层壁面函数承担，强加速吸力峰需要 low-Re 近壁（#12 表明需先解决
  稳态震荡，走瞬态+时均路线）；
- **基座/尾流**：基座吸力不足反映尾流压力恢复差，与无支腿简化
  （实验模型四腿抬升底部流动）及稳态 RANS 尾流模拟相关；
- **稳态 RANS 固有散布**：文献 20° 稳态 RANS Cd 散布 0.22–0.35。

## 结论与改进路线

十二轮可追溯实验表明：流程趋势自洽、所有数值真实可复算。绝对精度
Cd=0.449 vs 0.197（+128%），未达 ±10% 判据——**如实报告**。继续逼近
判据的路线（按性价比排序）：
1. 前缘盒 level6 + 尾流 level3 保持（预计 ~800 万单元，需要 >16GB 内存
   或分阶段网格）；
2. 低 Re 路线改瞬态（pimpleFoam）+ 长时间平均（#12 的稳态震荡提示
   尾流本质非定常）；
3. 几何补充支腿贴合实验模型。

本档案与 `workspace/*/results/verification_report.md` 一并构成可追溯的
验证记录；所有数值均为真实求解输出，无 dry-run 混入。
