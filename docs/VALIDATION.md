# Ahmed body 基准验证档案

> 基准：Ahmed et al. (1984), SAE 840300，Re ≈ 2.78e6（U=40 m/s，L=1.044 m，空气）。
> 流程：参数化 STL → 从零生成 case → blockMesh + surfaceFeatureExtract +
> snappyHexMesh + checkMesh → simpleFoam（k-ω SST 稳态 RANS，壁面函数）→
> forceCoeffs（迎风面积归一，稳态尾段均值）。运行时：WSL / OpenFOAM v2412。

## 已确认的系统性因素与修正记录

1. **尖角前缘**（#1 → #2）：平直前立面导致前缘大分离，Cd 达平板量级（~1.05）。
   加入实验几何的前鼻圆角（顶 R100 mm / 底 R50 mm）后 Cd 降至 0.58。
   结论：圆角是复现实验 Cd 的必要几何特征，已固化进生成器。
2. **网格分辨率与尾流**（#2 → #3）：表面加密 level 2→3 并加尾流加密盒，
   25° 工况 Cd 0.582→0.559，方向正确但幅度有限。
3. **区块阻塞比**（#4 → #5）：原域横截面对迎风面积阻塞比 ≈ 11%，超出
   汽车风洞 <5% 的工程惯例，会系统性抬高 Cd；已扩域至阻塞比 ≈ 4%。
4. **入口湍流**（#4 → #5 → #7）：I 1%→0.5%，随后改用远场粘度比
   nut/nu=5 定义 omega（外气动低湍流风洞惯例），Cd 0.547 → 0.493 → 0.487。
5. **上游地面滑移**（#5 → #6）：上游地面改 symmetryPlane（模拟风洞
   边界层吸除），仅体前 0.75L 起为移动地面；Cd 变化 <0.5%，非主导因素。
6. **wakeBox 语法根因**（#8）：#3–#7 的尾流加密盒采用内联 searchableBox
   写法，被 ESI 版 snappyHexMesh 静默忽略（日志 “entries were not used”），
   即此前各轮实际均无尾流加密；修正为 geometry 节定义 + refinementRegions
   按名引用后，#8 网格增至 115 万单元，Cd 仍≈ 0.49。

## 八轮实验的综合结论

设置级修正（几何圆角、阻塞比、入口湍流、地面处理、尾流加密）在 #1→#5
把 Cd 从 1.056 拉到 0.49 后全部进入平台期：剩余偏差由**模型形态因素**主导——
稳态 RANS + 壁面函数对斜面/基座分离的高估，以及无支腿简化几何与实验
（有支腿、有地面边界层控制）的差异。达到 ±10% 需低雷诺近壁处理的数百万
单元网格或瞬态尺度解析方法（DES/LES），超出本会话算力预算，列入后续路线。

## 剩余偏差来源（已确认无法在设置级消除）

- **稳态 RANS + 壁面函数**：对 20°/25° 斜面流动分离高估（文献 RANS 散布
  0.30–0.55+），需低雷诺近壁处理或瞬态方法改善；
- **简化几何**：无支腿（实验模型有四个支撑腿）、无附件；
- **地面边界层**：上游滑移处理后影响已降至次要（#6 实测 <0.5%）。

## 结论与改进路线

八轮可追溯实验表明：流程在**趋势与量级上自洽**（每次设置级修正同向
逼近实验值，并在 #5 后进入模型形态主导的平台期），绝对精度尚未达到
±10% 判据。达到判据的路线（按性价比排序）：
1. 网格加密至 300–500 万单元 + 低雷诺近壁处理（y+≈1，替代壁面函数）；
2. 25° 工况改用瞬态求解（pimpleFoam）或尺度解析方法（DES/LES）；
3. 几何补充支腿以贴近实验模型。

验证记录；所有数值均为真实求解输出，无 dry-run 混入。
